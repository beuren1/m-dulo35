# eFood (React + Styled Components + React Router)

Projeto base para o exercício da EBAC.

## Rodar o projeto
1. No terminal, dentro da pasta do projeto:
```bash
npm install
npm run dev
```

## Rotas
- `/` -> lista de restaurantes
- `/perfil/:id` -> página do restaurante + cardápio (com modal)

## Observações
- Layout inspirado no Figma do exercício.
- Dados mockados em `src/data/mock.ts`.
